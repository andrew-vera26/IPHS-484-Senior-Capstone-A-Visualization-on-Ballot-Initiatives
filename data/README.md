# data/

One folder per case: `sources/` holds the four source documents, `coding/` holds scaffolds, outlines and coded files.

**Every `*-EXAMPLE-coded.*` file here is model-coded and unaudited.** It is a hypothesis, not ground truth, and must not be used to evaluate the pipeline. Hand-coded ground truth lives only in `gold/`.

Anything shown on a page or site from these files must carry the label "model-coded, unaudited".
