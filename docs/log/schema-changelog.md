# Schema changelog

## v0.3 (proposed, not applied)
Batched gaps awaiting more cases: multi-witness time-indexed survival, `replaced_by`, a judicial-restoration Layer 1 value, `policy_pillar`.

## v0.2 (after the Missouri Prop A prototype)
- Added `provenance` and `provenance_basis`
- Added `depends_on` and `depended_on_by`
- Added top-level `dependency_affected` and `dependency_source_ids`, separated from `exemption_sweep`
- Added `parent_spine_id` and `counts_in_denominator`
- Added Layer 4 value `escalation removal`
- Replaced the typographic provision rule with the separate-survivability test
- Added validation rule: `outright repeal` implies `deleted entirely`

## v0.1
Initial nine-layer schema.

Note: v0.2 was applied by hand edits to the prototype file before the migration rule existed. Future changes go through migration.
