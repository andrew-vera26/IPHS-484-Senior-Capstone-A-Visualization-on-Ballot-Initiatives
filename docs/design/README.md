# Design

Design work is a separate track from the measurement pipeline. Order of work:

1. A planning model researches reference sites and writes `references.md`.
2. The same model writes `DESIGN.md`: views, interactions, and the exact data fields each view reads.
3. The prototype is built from `DESIGN.md` into `site-prototype/` and viewed on a local server only.
4. Nothing from the prototype is published until its data has been audited.

Because the design reasoning lives in these files, any model can continue the work.
