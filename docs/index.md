# What Survives

When voters pass a law by ballot initiative, the legislature can often amend or repeal it. Current records label a technical fix and a gutting the same way: *altered*. This project measures what actually survives, provision by provision, and publishes the evidence so anyone can check it.

**The claim in one sentence:** existing methods measure whether the text changed; this measures whether the law still does what voters voted for.
